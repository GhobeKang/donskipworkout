# 운동 출석 앱 UI — 원본 시안 비율 보정본

## 전달 상태

이 폴더는 기존 오렌지색 UI 이미지 4장을 기준으로 만든 **로컬 가져오기 패키지**입니다. 연결된 Figma 도구에서 Starter 플랜의 호출 한도 초과가 반환되어, 이 보정본을 기존 Figma 파일에 직접 저장하지는 못했습니다.

- 기존 파일: https://www.figma.com/design/pvEODPxWqrbM6dD08lO6Rw
- 플러그인은 기존 레이어를 삭제하거나 덮어쓰지 않고, 현재 페이지의 오른쪽 빈 영역에 새 보정본을 만듭니다.
- 이 패키지는 `.fig` 바이너리 파일이 아닙니다. SVG 4장과 로컬 개발 플러그인, PNG 미리보기, 원본에서 추출한 이미지 자산을 제공합니다.

## 가장 빠르게 결과 확인하기

`preview/overview.png`에서 네 화면을 한 번에 확인할 수 있습니다. `preview/`의 개별 PNG는 2배율 미리보기입니다.

`svg/`의 파일들은 글자를 윤곽선으로 바꾸어 저장했습니다. 폰트 대체 없이 시안을 확인하는 용도이며, Figma에 SVG를 가져와도 글자는 일반 텍스트가 아니라 벡터 경로입니다. 사진·캐릭터·손글씨는 내장된 래스터 이미지입니다.

## 편집 가능한 텍스트와 레이어로 가져오기

1. ZIP의 압축을 풀고 **Figma 데스크톱 앱**에서 대상 Figma Design 파일을 엽니다.
2. 캔버스에서 우클릭 → **Plugins → Development → Import plugin from manifest**를 선택합니다. 언어/버전에 따라 첫 메뉴는 `Select plugins`로 표시될 수 있습니다.
3. 이 폴더의 `figma-plugin/manifest.json`을 선택합니다.
4. Actions 또는 Plugins → Development에서 **Workout UI · 원본비율 보정**을 실행합니다.
5. 플러그인 창에서 **4개 화면 생성**을 누릅니다.

별도 npm 설치, 서버 실행, 빌드는 필요하지 않습니다. `manifest.json`, `code.js`, `ui.html`은 같은 폴더에 두세요.

필요 폰트: **Noto Sans KR / Regular, Medium, Bold, Black**. 네 가지가 없으면 임의의 폰트로 대체하지 않고, 캔버스를 만들기 전에 누락 글꼴을 안내합니다. 폰트 파일은 이 패키지에 포함되어 있지 않습니다.

Figma 공식 로컬 플러그인 가져오기 안내:
https://help.figma.com/hc/en-us/articles/38457121114263-Create-a-Figma-Design-plugin-with-the-Figma-MCP-server-and-agentic-tools

플러그인 manifest 참고:
https://developers.figma.com/docs/plugins/manifest/

## 생성하는 내용

| 화면 | 크기 | 주요 보정 |
|---|---:|---|
| 01 Today | 390 × 836 | 굵은 제목, 캐릭터와 말풍선, 시계·러닝 아이콘, 출석 진행 막대, 실제 과거 사진, 하단 내비게이션 |
| 02 Check-in | 390 × 886 | 카메라 점선 영역, 아이콘 버튼, 사진 안내, 캐릭터가 있는 확인 카드, 선택된 카메라 탭 |
| 03 Records | 390 × 962 | 달력 크기와 날짜 정렬, 상태 표시, 사진이 있는 최근 기록 5개, 아이콘 내비게이션 |
| 04 Settings | 390 × 910 | 섹션 아이콘, 구분선과 토글, 4단계 강도 카드, 캐릭터·문구 미리보기 |

외부 휴대폰의 금속 프레임과 촬영 배경은 제외하고 **앱 화면 내부**를 재구성했습니다. 생성 이미지마다 화면 비율이 달라, 390×844 하나로 강제하지 않았습니다. 실제 앱 개발 시 표준 뷰포트와 스크롤 정책은 별도로 정해야 합니다.

- 타이포그래피: 원본 이미지에는 정확한 폰트 메타데이터가 없습니다. 편집본에는 Noto Sans KR의 굵기·크기·자간·행간을 구분했습니다. `Black Han Sans`가 원본이라고 단정하거나 적용하지 않았습니다.
- 손글씨: 원본 시안에서 추출한 이미지입니다. 텍스트 내용 자체를 타이핑하여 고칠 수는 없습니다.
- 일반 제목/본문/숫자: 플러그인에서는 실제 TEXT 레이어입니다.
- 아이콘/카드/버튼/구분선: 실제 벡터/도형 레이어입니다. 아이콘은 비슷한 형태로 재작성한 SVG이며, 원본 아이콘 라이브러리를 확인한 것은 아닙니다.
- 사진/캐릭터: 기존에 제공된 시안에서 추출한 비트맵입니다. 새 인물이나 임의의 대체 캐릭터를 추가하지 않았습니다. 원본 이미지 해상도에 따른 확대 한계가 있습니다.
- 버튼/토글/내비게이션/상태바: 반복 요소는 공통 컴포넌트와 인스턴스로 생성합니다.
- 일부 버튼/행/목록: 오토레이아웃을 사용합니다. 캐릭터와 말풍선 같은 겹침 요소는 원본 위치를 재현하기 위한 고정 배치입니다.
- 디자인 파일만 생성하며, 실제 버튼 동작·푸시 알림·사진 촬영·프로토타입 전환 로직은 구현하지 않습니다.

## 원본 대비 의도적으로 정리한 문구

원본 이미지에 있던 오탈자를 바로잡았습니다. 설정의 “자존심을 분쇄할 것”은 초기 기획의 **인신공격 금지**와 충돌해 “핑계에만 가차 없이”로 바꾸었습니다. 사진 재사용 설명에는 사진별 제외가 가능하다는 원래 기획 원칙을 반영했습니다. 미실행 날짜에 사진이 보이는 등 원본 기록 시안의 데이터 표현은 시각 참고용이며, 실제 기록 데이터 검증을 의미하지 않습니다.

## 검증 범위와 한계

완료한 검증:
- 개별 SVG 4장을 PNG로 렌더링하고 시각적으로 검토했습니다.
- `code.js`의 JavaScript 구문 검사를 통과했습니다.
- Node.js의 Figma API 모의 환경에서 4개 화면 생성, 이미지 디코딩, 필수 폰트 확인, 공통 컴포넌트 생성, 폰트 누락 시 생성 중단을 검사했습니다.
- 모의 실행 결과: 화면 4개, 공유 컴포넌트 10개, 재사용 이미지 15개, 색상 변수 10개.

아직 완료하지 못한 검증:
- **실제 Figma 안에서 플러그인을 실행하고 결과를 재촬영하는 검증.** 연결 도구 한도로 진행하지 못했습니다.
- PNG/SVG 미리보기의 텍스트는 로컬 렌더러에서 Noto CJK 계열 윤곽선으로 생성하고 두꺼운 제목을 보정했습니다. Figma의 Noto Sans KR Black 렌더링과 글자 두께/줄 길이가 조금 다를 수 있습니다.
- 따라서 이 패키지를 ‘Figma에 최종 반영 완료’ 또는 ‘픽셀 단위로 완전히 동일’하다고 표시하지 않았습니다.

실행 오류가 발생하면 플러그인 창에 오류가 표시됩니다. 부분적으로 만들어진 새 영역은 실행 취소로 되돌릴 수 있습니다. 기존 화면은 건드리지 않습니다.

## 개인정보와 네트워크

플러그인의 모든 이미지가 `code.js`에 내장되어 있습니다. 외부 API를 호출하지 않고, 사진이나 캔버스를 서버에 전송하지 않습니다. 현재 페이지의 배치 공간과 사용 가능한 폰트/로컬 색상 변수를 확인한 뒤 새 레이어를 만듭니다.

## 폴더 구성

- `figma-plugin/` — 로컬 Figma 개발 플러그인
- `svg/` — 개별 화면 SVG, 글자는 윤곽선
- `preview/` — 개별 PNG와 전체 미리보기
- `assets/` — 원본 시안에서 추출한 캐릭터·사진·손글씨 PNG
- `references/` — 비교용 원본 화면 내부 크롭
- `design.json` — 레이아웃 좌표, 텍스트, 아이콘, 이미지 데이터
- `validation.json` — 로컬 검증 결과와 검증 범위
